# ⚡ EVCharge - Smart EV Charging Slot Booking System

EVCharge is a smart web-based EV charging slot booking system that helps electric vehicle users find charging stations, check slot availability, reserve charging slots, join queues, and receive notifications.

## 🚀 Features

- User Registration and Login
- JWT Authentication
- EV Vehicle Details
- Battery Percentage Tracking
- Charging Station Management
- Nearby Charging Station Search
- Smart Charging Station Recommendation
- EV Charging Slot Booking
- Double Booking Prevention
- Charging Queue Management
- Queue Position and Estimated Waiting Time
- Booking Cancellation
- Booking Completion
- Booking Notifications
- Queue Notifications
- 30-Minute Charging Slot Reminders
- My Bookings Dashboard
- Notification Management
